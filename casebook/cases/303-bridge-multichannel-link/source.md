# Bridge Multi Channel Link

The same housing search appeared in OpenClaw, a phone chat, and an email-forward thread.

The user explicitly said the OpenClaw thread and phone chat are the same Seattle housing search, but the email-forward thread is only a one-off listing from a friend.

The link action should share critical continuity between OpenClaw and phone chat while leaving email-specific details isolated.

The rollback path is to unlink the phone chat if the user later says it was a different search.
